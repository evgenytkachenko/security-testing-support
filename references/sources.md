# Primary sources

Checked November 14, 2026. Use the current organization-approved versions when applying this skill.

- OWASP Web Security Testing Guide, reporting and evidence-based testing: https://owasp.org/projects/web-security-testing-guide
- OWASP WSTG reporting guidance: https://owasp.org/www-project-web-security-testing-guide/stable/5-Reporting/README
- NIST SP 800-218, Secure Software Development Framework v1.1, vulnerability response and remediation practices: https://csrc.nist.gov/pubs/sp/800/218/final
- OASIS SARIF 2.1.0 plus Errata 01, format reference: https://docs.oasis-open.org/sarif/sarif/v2.1.0/sarif-v2.1.0.html

These references inform the workflow. The package is original coordination guidance, not an official compliance standard, full implementation of these documents, or endorsed scanner integration.
